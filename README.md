# 개인 소비 패턴 분석 및 예산 관리 시스템

> 2026년 오픈소스 프로젝트 개인과제 · 1반 6팀 · 20261685 임태연

개인의 지출 내역을 기록·저장하고, 항목별 지출 비율과 월별 소비 추이, 예산 대비 실제 지출을 대시보드로 보여주는 오픈소스 기반 시스템입니다.

## 주요 기능 (계획)

1. 지출 내역 입력·수정·삭제 (날짜, 소비 항목, 금액, 메모)
2. 월별·항목별 집계 및 시각화 (총지출, 소비 비율, 기간별 추이)
3. 월별 예산 설정 및 예산 초과 여부·잔여 예산 확인

## 사용 기술

| 기술 | 용도 |
| --- | --- |
| Python | 전체 로직 및 데이터 처리 |
| Streamlit | 웹 UI (입력, 조회, 필터링, 결과 표시) |
| Pandas | 날짜·항목별 집계, 합계·평균·비율 계산 |
| Plotly | 월별 추이, 항목별 비율, 예산 대비 지출 그래프 |
| SQLite | 지출 내역·예산 저장 (로컬 DB) |

## 시스템 흐름

```
지출 입력 → 데이터 검증 및 저장 → 집계 및 분석 → 그래프·통계 생성 → 대시보드 표시
```
